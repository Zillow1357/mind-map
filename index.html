      卡片是筆記的最小單位。白板把卡片和心智圖擺在一起，改任何一處，所有出現的地方都會更新。點標題可以進入各庫的完整頁面。

      只有這個分區的內容可以編輯，其他內容暫時淡化（Esc 返回）

      匯出／匯入

      匯出會包含所有卡片、白板和心智圖。資料只存在這個瀏覽器裡，請定期匯出備份。

      匯入時，貼上 JSON 或選擇檔案後按「匯入」，內容會合併進目前的工作區。也能匯入舊版心智圖工具匯出的 JSON，每一頁會變成一張心智圖。

      操作說明

      • 卡片：卡片就是筆記。同一張卡片可以放進多個白板，也可以接在心智圖節點上，改一處，每個地方都會更新。
      • 寫筆記：輸入「# 」變標題、「- 」變清單、「1. 」變編號、「[] 」變待辦、「> 」變引用、「---」加 Enter 變分隔線、「```」加 Enter 變程式碼區塊；輸入「/」開啟區塊選單。可貼上或拖入圖片。
      • 行內格式：輸入 **粗體**、*斜體*、`程式碼`、~~刪除線~~、==標亮== 後自動套用；網址後按空白自動變連結；選取文字會出現快速工具列。
      • 編輯快捷鍵：Ctrl＋B/I/U、Ctrl＋E 行內程式碼、Ctrl＋Shift＋H 標亮、Ctrl＋Shift＋X 刪除線、Ctrl＋K 連結、Ctrl＋Alt＋1/2/3 標題、Ctrl＋Shift＋7/8/9 編號／清單／待辦、Ctrl＋Shift＋↑↓ 移動整段、程式碼區塊內 Ctrl＋Enter 離開。標題、引用開頭按退格會變回一般段落。
      • 白板：拖曳卡片移動、拖右下角調整大小；選取卡片後拖四邊的圓點到另一張卡片就能連線；雙擊卡片開啟編輯。
      • 分區：拖曳分區標題時，裡面的卡片會一起移動。
      • 心智圖（只在白板上）：按「＋ 心智圖」或右鍵新增。點節點選取，兩側出現「＋」新增子節點；雙擊或 F2 改文字；拖曳節點到別的節點上換階層，放在同層之間調整順序；按住中心節點拖曳會移動整張心智圖。
      • 心智圖快捷鍵：Tab 新增子節點、Enter 新增同層、Delete 刪除、Alt＋↑↓ 調整順序、Ctrl＋C／X／V 複製、剪下、貼上節點（也能貼上縮排文字變成節點）。
      • 心智圖樣式與卡片：選取節點後按「顏色」可改填色、外框、文字色、字級、字體、粗細；右鍵可轉成卡片或連結既有卡片，轉成卡片的節點，雙擊或點文件圖示就能開啟卡片編輯；「外框」把整張心智圖像卡片一樣框起來；右鍵可匯出 PNG／SVG／Markdown。
      • 連線：從卡片邊緣的圓點拖到另一個物件；選取連線後按「連線樣式」可改顏色、粗細、實線／虛線／點線、兩端箭頭（無／實心／空心），以及文字大小、字體、顏色。心智圖不能自由連線。
      • 分區：分區像一個「包裹」，裡面的卡片、心智圖、連線在白板上都完整顯示；移動分區，裡面的內容會一起移動。按分區標題右側的「⤢ 開啟」（或選取後按 Enter），畫面會放大到這個分區並淡化其他內容，方便專注編輯，按「返回白板」或 Esc 離開。沒有第二層白板。
      • 卡片庫：Ctrl（或 ⌘）＋點選可選多張，Shift＋點選選範圍，選好後可整批拖進白板，或按右鍵開啟、加到白板、製作副本、刪除。卡片內輸入「/影片」或貼上 YouTube 網址，會出現可播放的縮圖。
      • 右鍵選單：在白板或節點上按右鍵（觸控長按），可複製、剪下、貼上，也能新增卡片、心智圖、便利貼、分區。
      • 圖片、PDF、影片：直接貼上（Ctrl＋V）或拖入圖片、PDF、影片網址，會變成白板物件，同樣能拖曳圓點連到卡片和心智圖。
      • 滑鼠：左鍵拖曳空白處框選；中鍵或空白鍵＋拖曳平移；滾輪捲動，Ctrl＋滾輪縮放。
      • 快捷鍵：Ctrl＋Z 復原、Ctrl＋Shift＋Z 重做、Delete 刪除。
      • 備份：資料只存在這個瀏覽器，請用「匯出／匯入」定期備份。
